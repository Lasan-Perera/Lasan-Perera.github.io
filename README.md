# Lasan Perera — Portfolio

My personal portfolio website. Live at **[lasan-perera.github.io](https://lasan-perera.github.io)**.

Electronic & Telecommunication Engineering undergraduate at the University of Moratuwa,
building robots, embedded systems and custom hardware.

## About

A single-page portfolio covering my experience, projects, and competition results — from
competition micromice to medical IoT devices. Built with plain HTML, CSS and JavaScript,
no frameworks. Features a light/dark theme toggle and a responsive layout.

## Built with

- HTML5
- CSS3 (custom properties for theming)
- Vanilla JavaScript
- Hosted on GitHub Pages

## Run it locally

Clone the repo and open `index.html` in any browser — no build step needed.

```bash
git clone https://github.com/Lasan-Perera/Lasan-Perera.github.io.git
```
